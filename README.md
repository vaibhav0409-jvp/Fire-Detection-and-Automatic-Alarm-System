## Project Description

This project is designed to detect the presence of a flame using a Flame Sensor. The sensor generates an electrical signal that controls a transistor-based switching circuit, activating a buzzer to produce an audible warning.
## Hardware Components

- Flame Sensor
- Transistor
- Buzzer
- Resistors
- Breadboard
- Jumper Wires
- Power Supply

## Working Principle

1. The flame sensor detects infrared radiation emitted by a flame.
2. The sensor generates an electrical output signal.
3. The output signal controls the transistor switching circuit.
4. The transistor activates the buzzer.
5. The buzzer produces an audible warning.
